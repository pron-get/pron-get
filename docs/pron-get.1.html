NAME
     pron-get, pron-cache - apt-style package manager for porn, over Tor

SYNOPSIS
     pron-get search [-page n] words ... | listing-url
     pron-get show package | url
     pron-get install [-q height] [-hls] [-j n] [-x n] [-limit n]
              [-search words] [-y] package | url | listing-url ...
     pron-get remove [-y] package ...
     pron-get update
     pron-get upgrade [-q height] [-j n] [-x n] [-limit n] [-y]
     pron-get list [-upgradable]
     pron-get add-source listing-url | search words [limit=n]
     pron-get edit-sources
     pron-get torcheck
     pron-get moo

     pron-cache search regex | show package | pkgnames | stats

DESCRIPTION
     pron-get is a simple command line interface for downloading and
     installing video packages.  It works almost like Debian's apt-get(8),
     except that a package is one video, named by its viewkey, and the archive
     is the website.  The most frequently used commands are update and
     upgrade.

     Every request goes through Tor.  If no Tor SOCKS proxy is running,
     pron-get starts a private tor(1) and stops it on exit.  Before any
     request reaches the site, check.torproject.org must confirm that traffic
     leaves through a Tor exit; otherwise pron-get refuses to continue and
     nothing is sent.

     Installed packages live in ~/pr0n/package/, one directory per video,
     holding the video file and a pkg.json manifest with its title, source,
     size and SHA-256.  Interrupted downloads keep a .part file and resume
     where they stopped.

COMMANDS
     search words ...
                   Search the site and print one package per line: an
                   installed mark (i), the package name, the duration and the
                   title.  -page n shows later result pages.

     search listing-url
                   List the videos on a model, pornstar, channel, user,
                   playlist or category page, following its pages up to -limit
                   n results (default 100, 0 for all).

     show package  Print the title, uploader, duration, homepage, install
                   status and every available version (quality and format) of
                   a package.

     install package ...
                   Download packages.  Arguments may be viewkeys, video URLs,
                   or listing URLs, which are expanded into the newest -limit
                   n videos of each (default 3, 0 for all).  -search words
                   adds the results of a search.  When listings are involved,
                   the packages to install are shown first and pron-get asks
                   before downloading.  Installing a package by name clears an
                   earlier remove.

     remove package ...
                   Delete packages after showing how much space is freed.
                   Removed packages are remembered, so upgrade does not bring
                   them back.

     update        Fetch every source in sources.list(5) and rebuild the
                   package index.  Each source is fetched on its own Tor
                   circuit.  A source that fails keeps its previous index
                   entries.

     upgrade       Install every package in the index that is neither
                   installed nor removed.  The list is shown, and confirmed,
                   before any network traffic.  -limit n installs at most n
                   packages.

     list          List installed packages, newest first.  With -upgradable,
                   list what upgrade would install instead.

     add-source source
                   Check a source and append it to sources.list.

     edit-sources  Open sources.list in VISUAL, EDITOR, or vi(1), then check
                   it.

     cache command
                   The same as pron-cache.

     torcheck      Connect to Tor and print the exit address that would be
                   used.

     moo           Has Super Cow Powers.

   pron-cache
     pron-cache queries the package index offline, like apt-cache(8).  It is
     the same binary: a symbolic link named pron-cache runs pron-get cache.

     search regex
               Print index entries whose name, title or source matches the
               case-insensitive regex.  Installed packages are marked i,
               removed ones r.

     show package
               Print what the index knows about a package.

     pkgnames  Print every package name in the index.

     stats     Print counts of indexed, installed, upgradable and removed
               packages, the number of sources, and the age of the index.

OPTIONS
     These options are accepted by every command:

     -dir dir       Where packages are installed.  Default: ~/pr0n.

     -tor host:port
                    Use this Tor SOCKS proxy.  By default pron-get starts its
                    own tor, so a system tor or Tor Browser closing mid-
                    download doesn't stop it.

     -tor-bin path  The tor(1) binary to start when -tor is not given.

     -sources file  The sources.list(5) to use.

     -index file    The package index to use.

     -site url      The site's base URL.  Default: https://www.pornhub.com.

     -onion         Use the site's onion service instead of a Tor exit.

     Options for install and upgrade:

     -q height      Highest quality to fetch, for example 720.  Default: the
                    best available.  If nothing is that small, the smallest
                    version is used.

     -hls           Prefer the HLS stream over the single MP4 file.  HLS
                    streams are remuxed to MP4 with ffmpeg(1) when it is
                    installed, and saved as MPEG-TS otherwise.

     -j n           Run n downloads in parallel (at most 8).  Each job has its
                    own Tor client and circuits.

     -x n           Fetch each mp4 over n connections (default 4, at most 8),
                    each on its own Tor circuit with its own signed media URL.
                    Tor limits speed per circuit, so this is about n times
                    faster.  -x 1 uses a single connection.

     -y             Assume yes; do not prompt.

SOURCES.LIST
     One source per line.  A source is a listing URL or search followed by
     words.  A trailing limit=n sets how many of the newest videos are indexed
     from it (default 40, 0 for all).  # starts a comment.

           https://www.pornhub.com/model/example-model
           https://www.pornhub.com/playlist/123456789 limit=100
           search oil massage limit=20

PRIVACY
     +   Tor or nothing: no request is made without a confirmed Tor exit, and
         HTTP_PROXY, HTTPS_PROXY and any system torrc are ignored.

     +   No DNS leaks: hostnames are resolved inside Tor.  The private tor
         runs with SafeSocks 1, which refuses any request that would need a
         local lookup.

     +   Unlinkable: every installed video, every update source and every
         parallel job uses a fresh circuit (IsolateSOCKSAuth), so the site
         sees each from a different exit.

     +   Tor Browser's User-Agent; cookies live in memory and die with the
         process.

     pron-get does not protect what is on your disk: ~/pr0n is ordinary files.
     The site still sees what is downloaded, just not by whom.

ENVIRONMENT
     XDG_CONFIG_HOME  If set, sources.list is read from
                      $XDG_CONFIG_HOME/pron-get/.

     VISUAL, EDITOR   Editor for edit-sources.

FILES
     ~/.config/pron-get/sources.list
             Sources for update; created with examples on first use.
     ~/Library/Caches/pron-get/index.json
             The package index built by update.
     ~/Library/Caches/pron-get/tor/
             State of the private tor (guards and consensus), kept so later
             runs start quickly.
     ~/pr0n/package/pkg.json
             Manifest of an installed package.
     ~/pr0n/.removed
             Packages that upgrade skips.

EXIT STATUS
     The pron-get utility exits 0 on success, and >0 if an error occurs.
     Usage errors exit with 1, bad options with 2, and failures with 100, like
     apt-get(8).  Interrupting a download exits with 130 and keeps the partial
     file.

EXAMPLES
     Find something and install it at 720p:

           $ pron-get search oil massage
           $ pron-get install -q 720 6a0123456789a

     Install the 10 newest videos of a model, three at a time:

           $ pron-get install -j 3 -limit 10 \
                 https://www.pornhub.com/model/example-model

     Follow a playlist and keep up with it:

           $ pron-get add-source https://www.pornhub.com/playlist/123456789
           $ pron-get update && pron-get upgrade -j 3

     Search the index offline:

           $ pron-cache search 'massage|spa'

DIAGNOSTICS
     Tor check failed, refusing to continue
             Tor could not be reached, or check.torproject.org did not see a
             Tor exit.  Nothing was sent to the site.

     media URL is bound to a different exit IP
             Video links are signed for one IP address, and some Tor exits
             send traffic from several.  pron-get resolves the video again on
             a new circuit and resumes.

     the site demands age verification from this exit
             The exit's country requires age verification.  pron-get does not
             bypass it; try again later from another exit.

     video is not available in the Tor exit's country
             The video is geo-blocked where the exit is.

HISTORY
     porn-get was written by tarzeau on 27 June 2001 "just for the fun of it"
     as the package manager of the joke distribution Lesbian GNU/Linux.  It
     was a bash script on top of lynx(1) and wget(1).  pl0pix rewrote it in
     2003 as version 0.5.1, the last release.  pron-get picks up the version
     numbering at 0.6.0.  The surviving releases are archived in history/ in
     the source tree.

AUTHORS
     tarzeau wrote porn-get in 2001 with "the PORN team";
     pl0pix rewrote it in 2003.  pron-get is by the pron-get contributors,
     2026.

BUGS
     Only public videos are supported.  Premium, private and locked videos are
     reported, not downloaded.

     The site's onion service was offline in November 2026, so -onion may not
     work.

     One Tor circuit carries about 0.5 to 1.5 MB/s; see -x and -j.
